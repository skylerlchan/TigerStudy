THE SYSTEM
Three Pillars of Acceleration
01

Memorize Faster

Maximum retention per minute invested

Spaced Repetition (Anki) Highest ROI

Create atomic flashcards after every class. Review 15 min/day. Material moves to long-term memory in 3-4 cycles. 2-3x better retention than cramming.

Evidence strength

Active Recall Critical

Close the book. Write everything you remember. Check what you missed. The struggle of retrieval is what encodes memory -- not re-reading.

Evidence strength

Interleaving

Alternate subjects in study blocks (3 subjects x 80 min, not 1 subject x 4 hrs). Builds flexible retrieval pathways.

Evidence strength
02

Output Faster

Eliminate the transcription tax

Voice-First Drafting You're doing this

Speak at 130-150 wpm instead of typing at 40-80. Use Whisper Flow for transcription, then clean up. You've already started this.

Speed gain

AI Drafting Pipeline

Voice-record your thinking (5-10 min) → Transcribe → AI structures into essay/report → You edit and refine. 30-45 min vs 3-4 hours.

Speed gain

Template Library

Build reusable templates for common assignment types (essays, lab reports, analyses). Never start from zero.

Speed gain
03

Protect Bandwidth

Hard boundaries between school and building

Time Blocking Foundation

School tasks get specific calendar blocks. When the block ends, school is done. No bleeding into build time. No "I'll just finish this."

Impact

Strategic Minimum Viable Effort

Identify which courses matter to you and invest deeply. For the rest, find the minimum effort for the grade you need. Not every class deserves 100%.

Impact

Batch Processing

Group similar school tasks together (all writing Mon, all problem sets Wed). Reduces context-switching penalty by up to 40%.

Impact

Daily System (30 min school overhead)

Morning

Anki Review

15 min. Review due cards. Non-negotiable. This maintains everything you've ever learned.

After class

Card Creation

5 min per class. Create atomic flashcards from key concepts while fresh.

Study block

Active Recall

Interleaved subjects. Test yourself, don't re-read. Use the assignment pipeline for any written work.

Before bed

10-min Reconstruct

Close eyes. Mentally reconstruct the day's key material. Sleep consolidates what you reviewed.
