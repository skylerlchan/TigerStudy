## Summary

### Granola AI Overview

- AI-powered meeting notes tool that combines transcript analysis with user input
- Creates “enhanced notes” automatically at meeting end
- Produces shareable, professional documentation with minimal effort

### Features of Granola

- **Notepad interface**
- Functions like regular text editor- Type anything during meeting- Located on right side of screen
- **Live transcript**
- Real-time voice capture- Green dancing bars indicator at bottom- Click to open/view transcript
- **Enhanced notes generation**
- Combines transcript content with user notes- Automatic processing at meeting end- Bright green button triggers generation

### Steps to Use Granola

- **During meeting**
- Write 1-2 lines of notes in notepad- Monitor transcript via green bars at bottom
- **End meeting**
- Click stop button at bottom of page- Click bright green “Enhanced Notes” button
- **Review output**
- System generates polished notes automatically- Combines transcript insights with manual notes
