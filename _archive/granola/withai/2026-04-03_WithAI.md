### How the Automation System Works

- Virtual machine runs a WithAI agent in the cloud with restricted internet access
- Can send emails to Mercator partner addresses- Can search the web (restricted version — no full Firecrawl to prevent data leakage)- Has access to: Companies folder, Research folder, Automation Center- No Bloomberg access on the VM

- Toggle publish/unpublish via send/X buttons in the UI- All team members can see each other’s automations
- To remove an automation: ask the agent to delete it — removes from shared folder entirely
- Parallel tasks available but compute-intensive — uses cloud token (high rate limit via YC) rather than Mercator Bedrock token
