# Q3 (Spring 2023) Prep Guide: Non-Standard Demand Problem

## The Question

Harry's preferences over Netflix hours (N) and Cable hours (C):

**u(N, C) = C^a + 2CN**

where a > 0 is a parameter.

**Parts:**
- **(a)** (8 pts) Show that if a <= 2, preferences are convex.
- **(b)** (5 pts) Write the indifference curve through (1, 1).
- **(c)** (12 pts) Find Marshallian demand if a = 2.
- **(d)** (12 pts) Resource is time, not money. (i) Budget constraint with T hours. (ii) How much time T to get utility u*?

---

## Part (a): Proving Convexity

### What they're really asking
Show that MRS is diminishing - i.e., the MRS (in absolute value) falls as you move along an indifference curve increasing C and decreasing N.

### The technique

Compute MU_C / MU_N and show it **falls as C rises and N falls**:

- MU_C = aC^(a-1) + 2N
- MU_N = 2C

So:

**MU_C / MU_N = [aC^(a-1) + 2N] / 2C = (a/2)C^(a-2) + N/C**

Now check each term as C increases and N decreases:

1. **N/C term**: N falls (numerator down), C rises (denominator up) => N/C decreases. Good.
2. **(a/2)C^(a-2) term**: The derivative in C is (a/2)(a-2)C^(a-3). This is **<= 0 when a <= 2**. So this term is weakly decreasing in C. Good.

Both terms move in the right direction => MRS is diminishing => preferences are convex.

### Key concept to internalize
Convexity = diminishing MRS. To prove it for a non-standard utility function, compute the MRS ratio and argue term-by-term that it moves in the right direction. The parameter restriction (a <= 2) is what makes the C^(a-2) exponent non-positive.

### Common mistake
Forgetting that you need to check the behavior with respect to **both** variables (C increasing AND N decreasing along the IC), not just one.

## Part (b): Indifference Curve

### Method
Plug (1,1) into the utility function to get the utility level, then set u(N,C) equal to that level.

u(1, 1) = 1^a + 2(1)(1) = 1 + 2 = 3

So the indifference curve is:

**C^a + 2CN = 3**

That's it. No need to solve for N as a function of C (though you could: N = (3 - C^a) / 2C).

## Part (c): Marshallian Demand (a = 2)

This is the meat of the question. With a = 2: **u(N, C) = C^2 + 2CN**

### Step 1: Equal bang-per-buck

MU_C / MU_N = p_C / p_N

With a = 2:
- MU_C = 2C + 2N
- MU_N = 2C

So:

**(2C + 2N) / 2C = p_C / p_N**

**1 + N/C = p_C / p_N**

**N/C = (p_C - p_N) / p_N**

**p_N * N = (p_C - p_N) * C**

Note: This gives N >= 0 only if p_C >= p_N.

### Step 2: Substitute into budget constraint

p_C * C + p_N * N = m

p_C * C + (p_C - p_N) * C = m

**(2p_C - p_N) * C = m**

**C* = m / (2p_C - p_N)**

Then back-substitute:

**N* = [(p_C - p_N) / p_N] * [m / (2p_C - p_N)]**

### Step 3: Check corner solution

If p_C < p_N, the bang-per-buck condition gives a negative N, which is infeasible. In this case, set N = 0 and spend everything on C:

**C* = m / p_C,  N* = 0**  (when p_C < p_N)

### Why corner solutions matter here
Unlike Cobb-Douglas (where both goods are always consumed), this utility function doesn't have a "goes to negative infinity at zero" property for N. Harry can get positive utility from C alone (u = C^2 when N = 0). So corner solutions are a real possibility.

### Pattern recognition
This is structurally similar to quasi-linear problems where you check whether the interior solution is feasible. The exam wants to see that you:
1. Derive the interior demand
2. Identify when it breaks down
3. State the corner solution

## Part (d): Expenditure Minimization with Time

### Part (i): Budget constraint

If both are free but time-limited, the constraint is just:

**C + N <= T**

This is equivalent to setting p_C = p_N = 1 and m = T.

### Part (ii): Minimum time to get utility u*

This is asking for the **expenditure function** (with "expenditure" measured in hours).

Since p_C = p_N = 1, use the demand from part (c):

Bang-per-buck gives: 1 + N/C = p_C/p_N = 1 => N/C = 0 => **N = 0**

So Harry watches zero Netflix when both cost the same per hour. His utility is:

u = C^2 + 2C(0) = C^2

Setting C^2 = u* gives **C = sqrt(u*)**, and total time needed:

**T = C + N = sqrt(u*)**

### The deeper insight
When prices are equal, Harry's MRS at any point where N > 0 satisfies MU_C/MU_N = 1 + N/C > 1 = p_C/p_N. This means cable always gives more bang-per-buck than Netflix at equal prices, so Harry goes all-in on cable. This is the corner solution from part (c) applied to the special case p_C = p_N.

## Likely Variations on an Exam

1. **Different utility function, same structure**: e.g., u = N^a + bNC. The workflow is identical: compute MRS, check convexity, derive demand, check corners.
2. **Asking for Hicksian demand instead of Marshallian**: Same tangency condition, but substitute into the utility constraint instead of the budget constraint.
3. **Comparative statics**: "What happens to demand for C as p_N increases?" Use your demand functions.
4. **Substitution/income effects**: Decompose a price change into Slutsky substitution and income effects using the compensated bundle.
5. **CES-type variants**: The 2025 exam Q1 used a CES utility and asked you to show it nests perfect complements, substitutes, and Cobb-Douglas as limits. Same flavor of "parameter controls the shape."
