## 🎯 The Big 5 - Master These First

1. **Expected Utility** → $EU = \sum p_i u(x_i)$ (NOT expected value!)
2. **Certainty Equivalent** → Solve $u(CE) = EU(L)$
3. **MR Formula** → If $P = a - bQ$, then $MR = a - 2bQ$ (twice slope!)
4. **Competition vs Monopoly** → Competition: $P = MC$, Monopoly: $MR = MC$
5. **Cost from Production** → Invert production function first, then multiply by wage

## 🚨 Most Common Mistakes

1. Using expected value instead of expected utility
2. Forgetting to invert production function
3. Using P = MC for monopoly (should be MR = MC!)
4. Wrong MR formula (must double the slope!)
5. Not checking corner solutions in portfolio problems
